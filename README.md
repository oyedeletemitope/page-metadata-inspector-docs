# Page Metadata Inspector Documentation

Documentation for [Page Metadata Inspector](https://github.com/oyedeletemitope/page-metadata-inspector), a Python command-line tool that retrieves metadata from web pages.

This documentation site is built with [Thally](https://github.com/thallylabs/thally).

## Documentation

The site contains three pages:

- **Introduction:** What Page Metadata Inspector does, who it is for, and its limitations.
- **Quickstart:** Install the tool and inspect your first page.
- **Inspect page metadata:** Run a local example, update HTML metadata, and compare the results.

The Python application and its tests are maintained in the [application repository](https://github.com/oyedeletemitope/page-metadata-inspector).

## Run locally

### Prerequisites

- Node.js 22.14 or later
- npm
- Git

Clone this documentation repository and install its dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3040.

## Project structure

- `docs.json`: Documentation navigation and feature configuration.
- `src/content/`: Documentation pages written in MDX.
- `src/data/site.ts`: Site name, description, links, and theme settings.
- `public/`: Static assets.
- `starter-release.json`: Thally starter version information.

The repository includes the Thally runtime and supporting files generated by the official starter.

## Validate changes

Run the available project checks:

```bash
npm run check
npm run typecheck
npm run build
```

The production build can be started locally with:

```bash
npm run start
```

## Publishing

The site can be published through Thally Cloud or deployed using a compatible Next.js hosting provider.

Documentation changes should be committed to this repository. Changes to the Python inspector belong in the separate application repository.
