# Page Metadata Inspector

Page Metadata Inspector is a Python command-line tool for developers who need to check the metadata their websites return. It fetches a public HTML page and prints the extracted values as JSON.

You can use it to check metadata after a deployment or investigate why a title, description, or canonical link is missing from the server's response.

## What the inspector reports

| Field | Description |
| --- | --- |
| `url` | Final URL after HTTP redirects |
| `title` | Text in the HTML `<title>` element |
| `description` | Content of the meta description tag |
| `canonical_url` | Canonical link resolved to an absolute URL |
| `og_title` | Content of the `og:title` meta tag |

If the inspector doesn't find a field, it returns `null` for that field.

## How it works

The tool requests the URL you provide, follows HTTP redirects, and reads up to 2 MB of HTML. It extracts metadata with Python's built-in HTML parser, so you don't need additional Python packages.

The inspector reads the HTML returned by the server. It doesn't execute JavaScript, so metadata added by client-side scripts may be missing. It also doesn't evaluate SEO quality or predict the title a social platform will display.
