Use Page Metadata Inspector to check the metadata a webpage returns in its HTML. You'll clone the Python application, inspect a public page, and read the JSON response.

## Prerequisites

Before getting started, you'll need:

- **Python 3.10 or later** to run the application.
- **Git** to clone the source repository.
- **An internet connection** to retrieve webpages.

Check that Python and Git are installed by running:

```bash
python3 --version
git --version
```

Page Metadata Inspector uses Python's standard library, so you don't need to install additional packages or configure API keys.

## 1. Download the application

Clone the [Page Metadata Inspector repository](https://github.com/oyedeletemitope/page-metadata-inspector) and change into the downloaded directory. You'll run the commands in the rest of this guide from there.

```bash
git clone https://github.com/oyedeletemitope/page-metadata-inspector.git
cd page-metadata-inspector
```

## 2. Inspect a webpage

To confirm that Page Metadata Inspector works, start with `example.com`. The command retrieves the webpage's HTML and prints any metadata it finds as JSON.

```bash
python3 inspector.py https://example.com
```

The response should look like this:

```json
{
  "url": "https://example.com",
  "title": "Example Domain",
  "description": null,
  "canonical_url": null,
  "og_title": null
}
```

Here, the inspector finds the page title but no values for the description, canonical URL, or Open Graph title. The output may differ if the website changes. For details about each field, see the [Introduction](/introduction).
